# toilettenwagen

Website für Toilettenwagen-hs — Vermietung von Toilettenwagen.

Gebaut mit **Next.js 16** (App Router), **React 19**, **TypeScript** und **Tailwind CSS v4**.

## Entwicklung

```bash
npm install      # Abhängigkeiten installieren
npm run dev      # Dev-Server auf http://localhost:3000
npm run build    # Produktions-Build
npm run lint     # Linting
```

## Arbeitsweise

Wir arbeiten nach dem Leitfaden **`WEB_WORKFLOW.md`** ("Direction before Code").
Der aktuelle Stand steht in **`docs/WORKFLOW_STATE.md`**, die Produktwahrheit in **`docs/DISCOVERY.md`**.
